# Проверка настроек Firebase для аутентификации

## Что нужно проверить в Firebase Console:

1. **Перейдите в Firebase Console**: https://console.firebase.google.com/
2. **Выберите проект**: `aurelo-a5296`
3. **Перейдите в Authentication**:
   - В левом меню выберите "Authentication"
   - Перейдите на вкладку "Sign-in method"
4. **Включите Email/Password**:
   - Найдите "Email/Password" в списке провайдеров
   - Нажмите на него и включите переключатель
   - Сохраните изменения

## Проверка доменов авторизации:

1. **В том же разделе Authentication**:
   - Перейдите на вкладку "Settings"
   - Найдите раздел "Authorized domains"
   - Убедитесь, что там есть:
     - `localhost` (для разработки)
     - Ваш домен сайта (например, `your-site.netlify.app`)

## Если аутентификация все еще не работает:

1. **Проверьте консоль браузера** на наличие ошибок
2. **Убедитесь, что Firebase SDK правильно подключен**
3. **Проверьте, что все зависимости установлены**:
   ```bash
   npm install firebase
   ```

## Тестирование:

1. Откройте сайт
2. Перейдите на `/auth`
3. Попробуйте зарегистрироваться с новым email
4. Попробуйте войти с существующими данными

Если все настроено правильно, аутентификация должна работать!
