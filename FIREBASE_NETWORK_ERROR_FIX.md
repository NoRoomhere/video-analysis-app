# Решение ошибки auth/network-request-failed

## Возможные причины и решения:

### 1. **Проблемы с настройками Firebase проекта**

**Проверьте в Firebase Console:**
- Перейдите в Firebase Console → Authentication → Settings
- Убедитесь, что в разделе "Authorized domains" есть ваш домен
- Для локальной разработки добавьте `localhost`
- Для продакшена добавьте ваш домен (например, `your-site.netlify.app`)

### 2. **Проблемы с API ключами**

**Проверьте конфигурацию:**
```javascript
// В src/firebase.ts должны быть правильные ключи
const firebaseConfig = {
  apiKey: "ваш-api-key",
  authDomain: "ваш-проект.firebaseapp.com",
  projectId: "ваш-проект-id",
  // ... остальные настройки
};
```

### 3. **Проблемы с сетью**

**Проверьте:**
- Подключение к интернету
- Блокировку файрволом
- Корпоративные прокси
- DNS настройки

### 4. **Проблемы с CORS**

**Для локальной разработки:**
- Убедитесь, что используете `localhost` или `127.0.0.1`
- Проверьте, что порт не заблокирован

### 5. **Проблемы с Firebase Quota**

**Проверьте в Firebase Console:**
- Перейдите в Usage → Authentication
- Убедитесь, что не превышены лимиты

## Пошаговое решение:

### Шаг 1: Проверьте диагностику
1. Откройте страницу `/auth`
2. Нажмите "Диагностика Firebase"
3. Посмотрите, какие компоненты показывают ошибки

### Шаг 2: Проверьте Firebase Console
1. Откройте https://console.firebase.google.com/
2. Выберите проект `aurelo-a5296`
3. Перейдите в Authentication → Settings
4. Проверьте "Authorized domains"

### Шаг 3: Проверьте настройки проекта
1. В Firebase Console → Project Settings
2. Убедитесь, что API ключи совпадают с кодом
3. Проверьте, что проект активен

### Шаг 4: Тестирование
1. Попробуйте зарегистрироваться с новым email
2. Проверьте консоль браузера на ошибки
3. Используйте диагностический компонент

## Если ничего не помогает:

1. **Создайте новый Firebase проект**
2. **Обновите конфигурацию в коде**
3. **Проверьте, что все зависимости установлены:**
   ```bash
   npm install firebase
   ```

## Дополнительная диагностика:

Откройте консоль браузера (F12) и проверьте:
- Ошибки в Network tab
- Ошибки в Console tab
- Статус запросов к Firebase

Если видите ошибки типа "CORS" или "Blocked by CORS policy", это означает проблемы с настройками доменов в Firebase.
